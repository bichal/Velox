# Changelog: Velox v0.1.1 (1.21 – 26.3)

Maintenance release. Same physics, same supported versions, same settings. Needs **Celeris** 0.3.1.1 or newer.

---

## Changes

* **Java Kernel by Default**: Velox no longer asks Celeris for its native kernel. In our CI tests the Java, JNI and FFM kernels give the same server tick, and the bit-for-bit check against the normal game passes with the Java kernel too. To use the native kernel anyway, add `-Dvelox.nativeKernel=true` to the server's Java arguments. `-Dceleris.physics.engine=java` still forces the Java kernel.
* **Clearer Log**: the startup line no longer suggests Java flags unless you asked for the native kernel.

## Documentation

* **Other Mods' Items**: the notes now say what the code does. Only plain vanilla item entities are handled; items from mods that use their own entity class, a changed gravity or a ride are left to the normal game.
* **Missing Celeris**: the troubleshooting page now says NeoForge stops the server with a missing-dependency error, because Velox never starts without Celeris.
* **Benchmarks**: the README now shows the Minecraft 26.1 results next to 1.21.1 (about 12× falling and 9× resting) and says the tests use plain items on solid ground, so farms with hoppers or slabs gain less.
